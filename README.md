# Космический Атлас 3D

Интерактивная 3D-модель Солнечной системы в одном файле `index.html` (Three.js r160).

## Что умеет

- **Реальные положения планет** на любую дату с 1800 по 2200 год — по кеплеровым элементам JPL (E. M. Standish, «Approximate Positions of the Planets»). Луна рассчитывается отдельно, поэтому в модели видна её настоящая фаза; Земля повёрнута к Солнцу так, как в выбранный момент.
- **Машина времени**: пауза, обратный ход, скорости от реального времени до года в секунду, переход к дате, список ближайших событий (противостояния, соединения, равноденствия, фазы Луны, возвращение кометы Галлея).
- **Два масштаба**: «Наглядный» (вся система на экране) и «Реальные расстояния» (истинные пропорции орбит).
- **Графика**: процедурное Солнце с грануляцией, пятнами, короной, протуберанцами и вспышками; Земля с огнями городов, облаками, бликом океана и атмосферой; тени колец Сатурна; Млечный Путь в реальной ориентации; пояс астероидов с люками Кирквуда, троянцы Юпитера, пояс Койпера; комета Галлея с ионным и пылевым хвостами.
- **Интерфейс**: лента планет, карточка объекта (обзор, данные, факты, «Вы там» — вес, возраст и время в пути), поиск (`/`), 5 экскурсий, энциклопедия с фильтрами и сравнением, снимок экрана, ссылка на текущий вид.

## Управление

| Действие | Мышь / клавиши | Телефон |
|---|---|---|
| Вращать камеру | левая кнопка | один палец |
| Приблизить | колесо | два пальца |
| Выбрать объект | клик | касание |
| Пауза | `Пробел` | кнопка времени |
| Скорость времени | `←` `→` | «Время» |
| Планеты | `1`–`9`, Солнце — `S` | лента внизу |
| Обзор системы | `0` | кнопка справа сверху |
| Поиск | `/` или `Ctrl+K` | лупа |
| Сейчас | `T` | «Время» → солнце |
| Облёт / снимок / скрыть интерфейс | `R` / `P` / `H` | «Ещё» |

Ссылка вида `index.html#o=saturn&d=2061-07-28` сразу открывает нужный объект и дату.

## Файлы

- `index.html` — всё приложение (стили, разметка, код).
- `textures/` — оптимизированные текстуры. Если их нет рядом с `index.html`, приложение загрузит их с CDN, а при недоступности CDN нарисует процедурные.

## Источники

- Положения планет: JPL Solar System Dynamics, «Approximate Positions of the Planets» (таблица 1, 1800–2050 гг.).
- Текстуры Земли и Луны: NASA Blue Marble / Black Marble (из примеров three.js, MIT).
- Карты планет: James Hastings-Trew (planetpixelemporium.com) через проект threex.planets (MIT).
- Числа спутников и сведения о миссиях — по состоянию на 2025 год.
